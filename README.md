# Marketplace Foundation

Build Phase 1 of a modern multi-vendor e-commerce storefront (customer-facing only):
- Project foundation with React, Vite, TypeScript, Tailwind CSS, Lucide React, Zustand, and TanStack Query.
- Clean, premium marketplace design system (typography, spacing, responsive layout, subtle shadows, clean borders).
- Sticky responsive header (desktop announcement bar, main navigation with search bar, categories menu, cart/wishlist counters, account menu; mobile drawer & search).
- Comprehensive marketplace footer (categories, customer service, store info, payment badges, newsletter signup).
- Homepage structure: promotional hero slider/banner, featured categories grid, flash deals section with countdown timer, trending products grid, best sellers, featured vendor/store cards, promotional banner, and new arrivals.
- Reusable components: ProductCard (with vendor badge, rating, wishlist, discount, add-to-cart), CategoryCard, StoreCard, DiscountBadge.
- Realistic mock data layer in src/data/ and modular API mock layer in src/api/ for products, categories, vendors/stores, flash sales, and cart.
